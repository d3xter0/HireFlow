# HireFlow Access Control Review

HireFlow is a recruitment platform used by applicants, recruiters, and administrators.

During an internal security review, the team identified an issue involving access to candidate-related resources. Some users appear to be able to access information that should be restricted according to ownership and role permissions.

Your task is to investigate the application and implement the necessary fix while preserving normal platform functionality.

Requirements:

* Maintain existing application behavior for legitimate users.
* Preserve role-based access rules.
* Ensure users can access only resources they are authorized to view.
* Do not remove features or change unrelated functionality.
* Keep the fix focused and minimal.

The application source code is available in the challenge directory.
